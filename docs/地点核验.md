# 三站地点核验记录

## 当前路线

1. **好再来大盘子（惠工社区店）**
   - 公开地址：辽宁省沈阳市沈河区惠工街三段东中南里。
   - 角色：惠工春日邮局，第一站集合和开场签到。
   - 坐标状态：尚未拿到可交叉验证的高德精确坐标。上线前使用高德地理编码或现场手机定位采集。

2. **中街—东中街附近**
   - 推荐集合锚点：东中街地铁站附近公共区域。
   - 公开坐标参考：`41.802831, 123.470596`。
   - 角色：红砖温室，主要观察和共同记忆玩法。
   - 坐标状态：该坐标可作为原型锚点；来源为公开百度结果，坐标系和高德底图可能存在差异。正式接入高德前必须重新地理编码或用高德定位采集 GCJ-02 坐标；最终停留位置仍要按当天人流、可停留空间和安全情况确认。

3. **狼头山火锅（东站店）**
   - 公开地址：辽宁省沈阳市大东区东北大马路 177 号 5 号楼 6 门；公开商户信息也出现“狼头山火锅KTV欢唱·烤串（东站店）”及东北大马路 177 号的名称变体。
   - 角色：东站夜光温室，终点祝福、密码和 22 支花。
   - 坐标状态：未拿到可交叉验证的高德精确坐标，且公开信息存在名称/营业状态变体。必须先电话确认门店仍营业、包间和布置许可，再用高德地理编码/现场定位定 GPS 围栏。

## 开发规则

- 原型可以使用区域近似点，但地图上要标注“路线坐标待现场校准”，不能把近似点当作最终签到范围。
- 不得把百度或其他地图来源的坐标直接当作高德 GPS 围栏；统一使用高德返回的 GCJ-02 坐标。
- 正式 GPS 围栏使用高德地理编码结果，再以现场手机定位复核；二维码作为最终到场确认。
- 不把公开电话、店铺地址或个人信息写入前端公开分享链接。
