# 《花园邮差：给小漾的 22 岁》安卓地图游戏策划案

## 一句话定义

这是一款只为五个人准备的安卓地图冒险游戏。现实中的沈阳路线是游戏世界的骨架，玩家在真实地图上移动、发现信件、领取装备、升级角色并解锁下一段路线；网页页面不再承担“逐页展示剧情”的职责，地图本身就是主界面。

## 这次重做的结论

当前网页版本的邀请页、任务卡片和线性章节页全部不作为新版本基础。新版本采用“地图常驻 + 底部任务抽屉 + 地图事件”的结构：

- 打开 App 直接进入沈阳魔幻地图，不先看长篇开场页。
- 主玩家始终有一个角色在地图上，角色等级、经验、装备和体力常驻在 HUD。
- 到达现实地点后，地图上的地标变成可交互事件；任务在地图上展开，不跳转成一页页的表单。
- 任务奖励改变地图能力，而不是只增加一个完成标记。
- 狼头山火锅东站店是地图上的“夜光温室”，22 支花是终章实体道具，不在开场提前展示。

## 目标体验

玩家感觉自己在一张“沈阳现实地图的田园幻想版”上旅行：道路、河流、街区和三个地点保持真实相对关系，但地图被重绘成柔和的花园、邮局、温室和夜间市集。它不是超级马里奥式的跳跃闯关，也不是旅游打卡，而是轻量的探索 RPG：移动、发现、对话、解谜、获得装备、升级和打开新的地图信息。

## 世界观与美术方向

### 世界观

小漾是“春日花园”的新任邮差。花园里有 22 封没有寄出的时光信，四位信使把信件散落在沈阳的三处现实坐标。她需要带着四位同行者，沿着城市的真实道路找回信件。每找回一封信，花园地图就恢复一块颜色；最后一封信藏在东站的“夜光温室”里。

### 视觉关键词

成熟的田园少女绘本、城市地图、植物标本、手绘路牌、柔和纸张、低饱和绿色、灰蓝天空、砖红屋顶、雾粉花朵、深棕墨线。

### 明确拒绝

- 不用粗黑描边、方块金币、问号砖块、跳跃蘑菇等马里奥语汇。
- 不使用幼儿园糖果色，不使用高饱和红黄蓝同时大面积出现。
- 不做像素 RPG，不仿制《星露谷物语》的角色、字体、地图素材或 UI。
- 不把任务做成三列卡片、长列表或连续弹窗。

### 画面层级

1. **地图底层**：高德真实地图 + 自定义地图样式，保留道路和水系的真实空间关系。
2. **幻想绘制层**：树冠、花田、邮局、温室、信件光点、手绘区域名和路线纹理。
3. **交互层**：玩家角色、可发现事件、路线线段、地标状态、定位范围。
4. **HUD 层**：等级、经验、体力、背包、当前任务和“打开导航”按钮。

## 现实路线设计

只保留两段闯关路程和一个终点，控制在 3–4 小时：

| 地图区域 | 现实地点 | 游戏地点 | 停留 | 主要玩法 |
|---|---|---|---:|---|
| 01 | 好再来大盘子（惠工社区店，惠工街三段东中南里） | 惠工春日邮局 | 30–40 分钟 | 领取邮差身份、选择角色天赋、拼合第一封信 |
| 02 | 中街—东中街附近（可用东中街地铁站作集合锚点） | 红砖温室 | 45–60 分钟 | 找植物印记、排列共同记忆、解锁花园地图 |
| 03 | 狼头山火锅东站店（东北大马路 177 号附近） | 东站夜光温室 | 2–3 小时 | 播放四人祝福、输入终章密码、领取 22 支花 |

正式开发前先用高德地图实地确认三个点的准确坐标、步行入口、营业时间和安全停留区域。当前公开核验记录见 `docs/地点核验.md`。地图游戏使用真实坐标，但不要求玩家为了完成任务进入收费区域或穿越危险道路。

## 核心游戏循环

```text
看见地图事件
  → 走到现实地点附近
  → 定位提示 + 二维码确认
  → 在地图上完成一个短玩法
  → 获得经验 / 装备 / 信件碎片
  → 地图新增可见区域或路线
  → 前往下一处现实地点
```

每个玩法控制在 2–8 分钟，不设置失败惩罚，不要求拍照打卡。定位失败时可以由发起人手动确认，二维码是最终确认手段。

## 主玩家成长系统

### 初始角色

玩家名为“小漾”，初始等级 Lv.1，拥有：

- 体力 3 点：用于触发地图探索事件，不影响现实行走。
- 经验 0 / 100。
- 空背包。
- 一张未完成的“春日邮差证”。

### 等级与奖励

| 等级 | 解锁 | 现实对应 |
|---|---|---|
| Lv.1 初见花园 | 显示春日邮局和第一条路线 | 惠工社区店集合 |
| Lv.2 记忆采集员 | 解锁“记忆放大镜”，可查看地图隐藏信件 | 中街解谜完成 |
| Lv.3 夜光邮差 | 解锁终章地图、祝福视频和花束提示 | 到达狼头山火锅东站店 |

### 装备与功能强化

装备不是装饰，它必须改变玩法：

- **心意徽章**：关键词任务完成后，地图上出现三条可选记忆线索。
- **记忆放大镜**：拼图完成后，点击地图植物标本可查看一段过去的共同回忆。
- **红砖罗盘**：第二站签到后，在地图上显示通往终点的真实路线方向。
- **信使铃**：两位朋友交出实体卡片后，终点祝福入口在地图上发光。
- **夜光邮票**：终章密码正确后，点亮 22 个花瓣并显示取花提示。

## 地图交互设计

### 主界面结构

- 地图占屏幕 70–80%，始终可见。
- 顶部左侧：玩家头像、Lv、经验条、体力。
- 顶部右侧：背包按钮、声音按钮、设置按钮。
- 地图中：三个主节点、支路、可发现信件、花园区域名称。
- 底部：可收起的“当前任务抽屉”，只显示当前任务和一个主操作。
- 点击地标：打开轻量底部面板，不离开地图。
- 点击“导航”：跳转高德地图 App 或网页导航，不在游戏内仿制完整导航。

### 地图状态

地图必须有明显的状态变化：

- 未发现区域：低饱和灰绿、植物剪影、不可读的信件标记。
- 已发现区域：恢复颜色，出现手绘植物和路牌。
- 当前任务节点：呼吸光点 + 方向线，不使用大红色箭头。
- 已完成节点：盖章、信件碎片和一枚装备图标。
- 终点节点：在第二站完成前只显示“夜光温室”，不写狼头山火锅东站店。

## 三站玩法

### 01 春日邮局：角色创建与第一封信

玩家在地图上走到好再来大盘子（惠工社区店）附近后触发邮局事件。四位朋友分别代表四种“邮差属性”：勇气、观察、记忆、陪伴。寿星选择一个最像自己的属性，其他三人通过实体卡片补充属性。

玩法不是表单，而是地图交互：点击邮局周围的三处植物标记，拖动三张词语标签到信封上，信封封口后获得“心意徽章”和 30 XP。随后二维码签到，地图第一段道路从灰色变为绿色。

### 02 红砖温室：记忆探索

玩家到达中街—东中街附近公共区域后，地图切换到红砖温室主题。地图会出现三个现实方位对应的手绘植物标本，玩家点击正确顺序，打开三张共同记忆卡。

玩法由三段短交互组成：

1. 观察局部色块，选择正确的红砖细节。
2. 将三段共同记忆拖成时间线。
3. 让两位男性朋友交出实体信使卡片，扫描二维码为卡片盖章。

完成后获得“红砖罗盘”、升级到 Lv.2，真实路线 Polyline 变为亮色，终点节点首次显示方向。

### 03 夜光温室：终章

玩家到达狼头山火锅东站店后，地图节点变成夜光温室。四人祝福视频按地图中四朵花的顺序播放，男朋友的祝福最后播放。

玩家输入你们约定的生日密码，正确后：

- 22 个花瓣在地图上逐个点亮。
- 显示 22 支花的现实领取提示。
- 播放最后一封信。
- 生成一张可保存的纪念地图海报。

## 高德地图与安卓技术方案

### 关键纠正

你提供的这段代码：

```html
window._AMapSecurityConfig = {
  serviceHost: "https://xn--sama-px9gg69g.top/_AMapService"
};
```

是高德 **Web JS API** 的配置，不能直接作为原生安卓地图 SDK 的接入方式。安卓 App 需要在高德控制台新增 **Android 平台 Key**，绑定应用包名和 SHA-1；不能把 Web 端 Key 原样当作安卓 Key 使用。

### 推荐技术栈

- Kotlin
- Jetpack Compose
- `com.amap.api:3dmap` 或当前高德 Android 地图 SDK
- AMap Location 定位 SDK
- AMap Search / Route SDK（仅用于坐标校验和导航入口）
- Room 或 DataStore 保存本地房间进度
- ViewModel + StateFlow 管理游戏状态
- Android Canvas / Compose Canvas 绘制幻想地图覆盖层

### 地图实现方式

采用“高德真实地图 + 幻想覆盖层”的混合方案：

1. 高德 `MapView` 负责真实道路、坐标、缩放、定位和版权标识。
2. 关闭不需要的 POI 图层，使用高德自定义地图样式降低现实地图的视觉干扰。
3. 使用 `Polyline` 绘制三站游戏路线。
4. 使用 `Marker` 放置邮局、温室和终点。
5. 使用 Compose Overlay 或 Android Canvas 在 Marker 上方绘制花田、信件光点、区域标题和角色状态。
6. 所有幻想节点仍绑定真实经纬度，因此“魔幻改绘”不会变成一张与现实脱离的假地图。

### 安卓端密钥安全

- 新建 Android 平台 Key，并绑定正式包名和签名 SHA-1。
- Web Key、Android Key 分开管理。
- 不把 `securityJsCode` 写入仓库，不把 Web 的 `serviceHost` 当作 Android 配置。
- 高德 Web 服务如果由服务器调用，继续由 `154.201.65.68` 上的 Nginx / 后端代理转发。
- APK 内的 Android Key 不是绝对机密，必须依靠高德平台限制、包名和 SHA-1 限制降低滥用风险。

## 素材制作与来源

### 必须自己采集

- 五人当天合照和终点包间布置照片。
- 过去共同经历的 6–12 张照片。
- 两站 6–9 张建筑局部和植物细节照片。
- 四段竖屏祝福视频。
- 22 个具体愿望短句。

### 可在线获取的素材

| 素材 | 推荐来源 | 用途 | 注意 |
|---|---|---|---|
| 田园植物、纸张、手绘纹理 | OpenGameArt、Kenney、itch.io 免费包 | 地图覆盖层与 UI | 每个包单独检查 CC0 / CC BY / 商用限制 |
| 真实沈阳地图 | 高德 Android SDK | 底图、道路、定位 | 保留版权标识，遵守 SDK 条款 |
| 音效 | Freesound、Pixabay Audio | 邮件、盖章、升级音效 | 记录作者和许可证，不自动播放背景音乐 |
| 字体 | 思源宋体 / 思源黑体等开源字体 | 标题与正文 | 随 APK 或仓库保留许可证 |
| 植物插画 | 自绘、委托绘制或图像生成后人工统一风格 | 幻想覆盖层 | 不使用星露谷拆包资源，不直接复制他人角色 |

### 素材风格标准

所有地图插画必须统一为“水彩植物 + 细墨线 + 低饱和色块”，不要混用像素、3D 卡通、扁平 emoji 和写实照片。照片只进入记忆卡和终章海报，不能让地图风格跳变。

## 版本范围

### V1 必须完成

- Android APK，可在一台手机上完整运行。
- 高德真实地图、三个真实坐标节点和一条路线。
- 定位提示 + 二维码手动确认。
- 玩家 Lv.1–Lv.3、经验条、体力、背包。
- 三站地图事件和五个装备能力。
- 22 花瓣终章、祝福视频占位、纪念地图海报。
- 无网络或定位失败时的手动完成模式。

### V1 不做

- 多房间实时联机。
- 用户注册、支付、公开分享社区。
- 复杂战斗、敌人、排行榜。
- 大范围自由探索和大量支线。
- 为了“看起来像游戏”加入无意义的跳跃、金币和抽卡。

## 开发阶段

### 阶段 1：地图原型

先只做一个 Android MapView：高德底图、三个 Marker、Polyline、当前位置、底部任务抽屉。用真实手机测试地图缩放、定位权限和网络异常。

### 阶段 2：游戏状态

加入角色等级、经验、装备、节点状态、二维码签到和手动确认。所有状态可以离线保存在本机。

### 阶段 3：幻想地图

加入自定义地图样式、植物覆盖层、信件光点、区域标题和动画。先统一一套画面语言，再批量制作三站素材。

### 阶段 4：生日内容

接入真实照片、视频、愿望短句、终点密码和纪念海报。用一台手机完整走模拟路线，再现场踩点测试。

## 验收标准

1. 打开 App 直接看到沈阳地图，不出现长篇欢迎页。
2. 三个节点在真实地图上的相对位置正确，路线不穿越明显危险区域。
3. 玩家完成任务后，地图视觉和功能发生变化，而不是只显示“已完成”。
4. 不需要拍照打卡，不需要注册，不会因为 GPS 漂移阻塞流程。
5. 安卓手机竖屏下地图操作、底部任务抽屉和按钮均可用。
6. 没有任何星露谷或超级马里奥的直接素材、字体和角色复制。
7. 高德版权信息、定位权限说明和隐私提示完整存在。
8. 从 Lv.1 到终章可以在 3–4 小时内完成，不要求跑遍四个城区。

## 需要先确定的三项内容

1. 狼头山火锅东站店的高德准确坐标、可停留入口和包间安排。
2. 好再来大盘子（惠工社区店）的高德准确坐标、集合门口和二维码放置位置。
3. 中街—东中街附近最终停留的公共点位、可停留范围和现场拍摄角度。

这三项确定后，地图坐标、路线线段、二维码内容和现场任务才能进入制作阶段。
